# UCM Implement use case website

Static website presenting the proposed Agentforce use cases for the UCM Access
Center.

## Run locally

```bash
npm start
```

Open `http://localhost:3000`.

## Validate JavaScript

```bash
npm run check
```

## Heroku

The site includes a dependency-free Node static server and a `Procfile`. It is
ready to be deployed as its own Heroku application after design and content
approval.
